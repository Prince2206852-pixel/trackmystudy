# TrackMyStudy 📚

**Make every hour count.**

TrackMyStudy is a simple, installable Progressive Web App (PWA) designed to help students track their study time, manage daily goals, and build consistent study habits.

## ✨ Features

- **Daily study planner** — Create, rename, and customize tasks with individual time targets.
- **Focus timer** — Start, pause, and switch between study sessions.
- **Progress tracking** — Monitor study time and target completion percentages.
- **Study analytics** — Visualize your study activity across days, weeks, months, and years.
- **Offline-friendly experience** — Access the app after its resources have been cached.
- **Privacy-first design** — No account or email login required. Study data is stored locally in your browser.
- **Backup and restore** — Export your study data and restore it later.
- **Installable PWA** — Add TrackMyStudy to your mobile home screen.

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- CSS
- Browser Local Storage
- Progressive Web App technologies

## 🚀 Run Locally

### Prerequisites

Install Node.js from [nodejs.org](https://nodejs.org/).

### Installation

```bash
git clone https://github.com/Prince2206852-pixel/trackmystudy.git
cd trackmystudy
npm install
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
```

The production files will be generated in the `dist` directory.

## 📱 Install on Mobile

Once the app is deployed over HTTPS, open its website in a compatible mobile browser and select **Install app** or **Add to Home screen**, if available.

## 🔒 Privacy

TrackMyStudy does not require user accounts. Study tasks and history are stored locally on the device. Data does not automatically synchronize across devices, so export a backup before changing devices or clearing browser data.
